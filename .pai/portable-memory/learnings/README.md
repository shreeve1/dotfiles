# Learnings (placeholder)

Convention overlay for portable memories with `type: "learning"`.

These are **synthesized** durable learnings (reviewed, accepted, trusted) — not raw session logs, JSONL trails, or reflection events. Raw learning event logs stay local under `~/.pai/` and are excluded by `.gitignore`.

The canonical memory type is still `learning` in the SQLite store. This directory is an organizational view for humans browsing the dotfiles repo.

See [`../README.md`](../README.md) for the full portable memory contract.
