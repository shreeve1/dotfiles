# Procedures (placeholder)

Convention overlay for portable memories with `type: "procedures"`.

These are reviewed, accepted procedures the operator wants to carry across machines (e.g. "run typecheck before commit", "always export portable memory before reinstalling PAI").

The canonical memory type is still `procedures` in the SQLite store. This directory is an organizational view; the source of truth is `exports/accepted-memories.json`.

See [`../README.md`](../README.md) for the full portable memory contract.
