# Memory Skill

Persistent memory system using SQLite with FTS5 search. Stores sessions, learnings, and checkpoints across projects.

## Activation

```
/mem                           # Browse recent (default)
/mem "query"                   # Search memories
/mem search "query"            # Explicit search
/mem save                      # Save current session
/mem save "description"        # Save with description
/mem global                    # Save cross-project learning (interactive)
/mem global "learning"         # Save learning directly
/mem checkpoint                # Mid-session snapshot
/mem checkpoint "description"  # Checkpoint with description
/mem cleanup                   # Consolidate old entries
/mem cleanup 30                # Entries older than 30 days
/mem plan path/to/plan.md      # Resume from plan file
```

## CLI Path

All commands use: `~/.claude/skills/mem/scripts/mem-cli.py`

For detailed CLI arguments, output schemas, and error handling, see `references/cli-reference.md`.

## Mode: Browse (no arguments)

Display recent memories from both scopes.

**Execute in parallel:**
```bash
python3 ~/.claude/skills/mem/scripts/mem-cli.py list --scope project --project-path "$(pwd)" --limit 5
python3 ~/.claude/skills/mem/scripts/mem-cli.py list --scope global --limit 5
```

**Display format:**
```
## Recent Memories

### Project Sessions (N)
1. [#id] <description> (<date>)
2. [#id] <description> (<date>)

### Global Learnings (N)
1. [#id] <description> [category] (<date>)
```

If empty: "No memories yet. Use `/mem save` or `/mem global` to create some."

Then offer drill-down via AskUserQuestion: "View project session", "View global learning", "Search", "Done".

## Mode: Save

Save current session transcript and file changes to project memory.

**If no description provided:** Auto-generate from session context (summarize what was accomplished in 1-2 sentences).

**Steps:**

1. Locate transcript at `~/.claude/transcripts/ses_{session-id}.jsonl`
2. Generate description if not provided
3. Execute:
```bash
cat ~/.claude/transcripts/ses_{session-id}.jsonl | python3 ~/.claude/skills/mem/scripts/mem-cli.py save-project --project-path "$(pwd)" --description "<description>"
```

**Display result:**
```
Session saved!

Description: "<description>"
Files tracked: N
Transcript chunks: N
Session ID: <id>
```

---

## Mode: Global

Save a cross-project learning.

**If description provided directly:**
```bash
echo '<auto-generated content>' | python3 ~/.claude/skills/mem/scripts/mem-cli.py save-global --description "<learning>" --category "general" --source-project "$(pwd)"
```

**If no argument (interactive):**

1. AskUserQuestion: "What did you learn or want to remember?"
2. AskUserQuestion: "Category?" Options: pattern, preference, lesson, technique, general
3. AskUserQuestion: "Tags? (comma-separated, optional)" Options: "No tags"
4. Auto-generate detailed content from session context
5. Save with chosen category and tags

**Display result:**
```
Learning saved!

Description: "<learning>"
Category: <category>
Tags: <tags>
ID: <id>
```

## Mode: Checkpoint

Save mid-session snapshot with task state for clean handoff.

**Steps:**

1. **Accept description** - use provided or auto-generate
2. **Generate resume context** - structured summary:
   ```
   Goal: <what session set out to accomplish>
   Done: <bullet list of completed items>
   In Progress: <actively being worked on>
   Next: <what should happen next>
   Decisions: <key technical decisions>
   Blockers: <any blockers>
   ```
3. **Discover task directory:**
   ```bash
   ls ~/.claude/tasks/ 2>/dev/null
   ```
   If multiple, use AskUserQuestion to pick. If none, proceed without.
4. **Discover plan file:**
   ```bash
   ls -t artifacts/plans/*.md specs/*.md 2>/dev/null | head -1
   ```
   Use most recently modified.
5. **Update plan file** (if found) - add/replace `## Checkpoint Progress` section:
   ```markdown
   ## Checkpoint Progress

   **Last Updated:** <ISO timestamp>
   **Checkpoint ID:** <session_id>

   ### Completed Tasks
   - <completed tasks>

   ### In Progress
   - <in-progress tasks>

   ### Next Steps
   - <from resume context>

   ### Decisions
   - <from resume context>

   ### Blockers
   - <from resume context or "None">
   ```
6. **Save checkpoint:**
   ```bash
   cat ~/.claude/transcripts/ses_{session-id}.jsonl | python3 ~/.claude/skills/mem/scripts/mem-cli.py save-checkpoint \
     --project-path "$(pwd)" \
     --description "<description>" \
     --task-dir "<task-dir-name>" \
     --resume-context "<resume-context>" \
     --plan-path "<plan-path>"
   ```

**Display result:**
```
Checkpoint saved!

Description: "[CHECKPOINT] <description>"
Tasks snapshotted: N (M active)
Transcript chunks: N
Resume context: saved
Plan tracked: <plan-path>

To resume: /mem plan <plan-path>
```

## Mode: Cleanup

Consolidate old memory entries. Prefers merging over deletion.

**Parse threshold:** Default 7 days, or use provided number (1-365).

**Execute in parallel:**
```bash
python3 ~/.claude/skills/mem/scripts/mem-cli.py list-old --scope project --project-path "$(pwd)" --older-than-days <N>
python3 ~/.claude/skills/mem/scripts/mem-cli.py list-old --scope global --older-than-days <N>
```

**Display grouped by age:**
```
## Memory Cleanup (entries older than N days)

### Project Sessions (X)
**7-14 days:**
1. [#id] description (N days old)

**14-30 days:**
...

**30+ days:**
...

### Global Learnings (X)
...
```

**Actions via AskUserQuestion:**
- "Consolidate project sessions" - Merge related into summaries
- "Consolidate global learnings" - Merge related learnings
- "Delete specific entries" - Remove by ID
- "Keep all" - Exit

**Consolidation process:**
1. Read full details of all old entries
2. Identify related groups (same topic, feature, etc.)
3. Present groupings to user
4. For each group, AskUserQuestion: "Consolidate", "Keep separately", "Delete"
5. If consolidate: generate summary, show to user, confirm, then save and delete originals
6. **CRITICAL: Every deletion requires explicit AskUserQuestion confirmation**

**Display summary:**
```
## Cleanup Complete

Project Sessions:
- Consolidated: X -> Y entries
- Deleted: Z entries

Global Learnings:
- Consolidated: X -> Y entries
- Deleted: Z entries
```

## Mode: Plan Resume

Resume work from a plan file with checkpoint history.

**Steps:**

1. Read plan file
2. Display `## Checkpoint Progress` section if exists
3. Search related checkpoints:
   ```bash
   python3 ~/.claude/skills/mem/scripts/mem-cli.py search --scope project --project-path "$(pwd)" --query "checkpoint" --plan-path "<plan-path>" --limit 3
   ```
4. Display plan state and checkpoints
5. Offer to view full checkpoint details

## Display Record Details

When user selects an entry to view:

**Project session/checkpoint:**
```bash
python3 ~/.claude/skills/mem/scripts/mem-cli.py show --scope project --project-path "$(pwd)" --id <id>
```

If checkpoint (`metadata.type == "checkpoint"`):
- Description, date
- Resume Context (blockquote)
- Active tasks from snapshot
- Git branch/commit if available
- File changes (condensed)
- If plan_path: show Checkpoint Progress section

If regular session:
- Description, date
- Git branch/commit
- File changes
- Summary: 2-3 bullets max

**Global learning:**
```bash
python3 ~/.claude/skills/mem/scripts/mem-cli.py show --scope global --id <id>
```

Display: description, category/tags, content (truncate 500 chars), source project, date.

## Key Behaviors

- Always run project + global queries in parallel
- Keep output concise - truncate descriptions to 80 chars in lists
- Skip empty scopes (don't show "Sessions (0)")
- Summarize transcripts, never dump raw content
- Every destructive action requires AskUserQuestion confirmation
- Checkpoints get `[CHECKPOINT]` prefix automatically
- Plan paths stored relative to project root for portability

## Storage

- Project memory: `~/.claude/data/memory/projects/{hash}/memory.db`
- Global memory: `~/.claude/data/memory/global/memory.db`
- FTS5 enabled for full-text search
