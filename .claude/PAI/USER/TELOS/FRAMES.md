# Mental Frames

Lenses through which James sees problems and opportunities.

## Everything Is a System
Every problem, organization, and workflow is a system with inputs, processes, and outputs. Understanding the system is the prerequisite to improving it.

## Find the First Step
When facing complexity, don't try to comprehend the whole thing at once. Figure out what the first step is. Then the next. Process emerges from action.

## Technology Should Serve People
Tech exists to make life easier for the people using it. If a solution makes things harder or more confusing, it's not a solution — it's a different problem.

## The Builder's Lens
Understanding comes through building. Reading about Kubernetes teaches concepts; running a 4-node production cluster teaches reality. Hands-on trumps theoretical.

## Escalation Thinking
From years as the escalation point at MSPs: problems have layers. If tier 1/2 couldn't solve it, the issue is deeper than it appears. Don't start with the surface — dig to root cause.
