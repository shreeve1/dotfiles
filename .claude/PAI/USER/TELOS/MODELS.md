# Mental Models

Decision-making frameworks James uses consistently.

## The Rule of Two
If you do something twice, automate it. Human attention is finite and expensive. Repetitive tasks are automation candidates.

## Systems-First Diagnosis
When something breaks: understand the system, identify the layer, isolate the component, fix the root cause. Don't shotgun fixes.

## Learn by Shipping
The fastest path to understanding is building something real. Side projects and toy examples teach basics; production systems teach truth.

## The Golden Rule Filter
Before acting — especially in management — ask: "Would I want this done to me?" Applies to delegation, feedback, process changes, and client interactions.

## Escalation Triage
From MSP experience: assess urgency, identify blast radius, determine if this is a known pattern or novel failure. Route accordingly.

## Progressive Complexity
Start simple, add complexity only when justified. A bash script before Ansible. Docker before Kubernetes. Solve the problem you have, not the problem you might have.
