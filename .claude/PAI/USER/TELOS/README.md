# TELOS — Personal Life Operating System

James Schriever's personal context system. All files at `~/.claude/PAI/USER/TELOS/`.

## Files

| File | Purpose |
|------|---------|
| `TELOS.md` | Main framework — career timeline, identity, current state |
| `MISSION.md` | Life mission statement |
| `BELIEFS.md` | Core beliefs and worldview |
| `WISDOM.md` | Accumulated wisdom and insights |
| `BOOKS.md` | Books that shaped thinking |
| `MOVIES.md` | Media preferences |
| `LEARNED.md` | Lessons learned over time |
| `WRONG.md` | Things previously wrong about (growth tracking) |
| `FRAMES.md` | Mental frames and perspectives |
| `MODELS.md` | Mental models for decision-making |
| `NARRATIVES.md` | Personal narratives and self-stories |
| `STRATEGIES.md` | Active life strategies |
| `GOALS.md` | Short, medium, and long-term goals |
| `PROJECTS.md` | Active projects (ITAStack, Agent Zero, Homelab, PAI) |
| `PROBLEMS.md` | Problems to solve |
| `CHALLENGES.md` | Current challenges |
| `PREDICTIONS.md` | Predictions about the future |
| `TRAUMAS.md` | Past traumas (for context) |
| `updates.md` | Changelog of all TELOS updates |

## Usage

- **Read**: Load any file directly by path (e.g., `~/.claude/PAI/USER/TELOS/GOALS.md`)
- **Update**: Use the Telos skill's Update workflow — never edit directly
- **Job Search**: Telos skill's JobSearch workflow uses these for career translation and interview prep
