# Scenario: Researching Best Practices for Technical Decision

You are the web-searcher for a full development team. The dispatcher has sent
you this task:

---

"The planner is designing a file upload feature for our Express.js API. We need
current best practices for handling file uploads in Node.js/Express — security
considerations, recommended libraries, size limits, file type validation, and
storage approaches (local vs. cloud). Focus on production-grade recommendations,
not tutorial-level basics."

---

Research this topic and produce a report that the planner can use to make
informed technical decisions.
