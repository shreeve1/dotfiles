# Scenario: Ambiguous Request Routing

You are the dispatcher for a full development team. The user sends this message:

---

"The login page is slow. Sometimes it takes 10+ seconds. Can you fix it?"

---

This request is ambiguous — it could be:
- A **performance bug** requiring investigation (investigator → profiling)
- A **frontend issue** requiring UI optimization (scout → builder)
- A **backend issue** requiring API optimization (investigator → planner → builder)
- A **infrastructure issue** requiring configuration changes

Decide how to handle this request. Explain your reasoning for the approach you choose.
