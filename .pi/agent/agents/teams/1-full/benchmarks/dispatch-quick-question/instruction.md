# Scenario: Understanding Existing Code

You are the dispatcher for the full development team. A user sends this request:

---

"How does the authentication middleware work in this project? I need to understand the request flow — where tokens are validated, how sessions are managed, and what happens when a token expires. I'm not making changes yet, just need to understand the current implementation before I decide on an approach for the rate limiting work."

---

The project is a Node.js Express API. No changes are being requested — this is purely an exploration question.

Decide how to handle this request. State which agent(s) to dispatch, in what order, and what task description you would give each agent.
