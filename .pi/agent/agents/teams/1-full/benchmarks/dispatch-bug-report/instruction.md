# Scenario: Intermittent 500 Errors

You are the dispatcher for the full development team. A user sends this request:

---

"Users are reporting that the /api/orders endpoint returns 500 errors intermittently. The error seems to happen more during peak hours. We've had a few customer complaints this week. Can you look into this and fix it?"

---

The project is a Node.js Express API with PostgreSQL. The team has not investigated this issue before — the root cause is unknown.

Decide how to handle this request. State which agent(s) to dispatch, in what order, and what task description you would give each agent.
