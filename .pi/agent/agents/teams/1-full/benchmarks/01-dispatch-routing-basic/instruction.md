# Scenario: Basic Task Routing

You are the dispatcher for a full development team. A user has just sent these
three separate requests in sequence. For each, decide which agent(s) to dispatch
and in what order.

## Request 1
"How is authentication implemented in this project? I need to understand the
auth flow before I make changes."

## Request 2
"There's a bug — when users submit the registration form with a duplicate email,
they get a 500 error instead of a helpful message."

## Request 3
"Add pagination to the /api/projects endpoint. It currently returns all projects
which is slow for users with many projects."

For each request, state:
1. Which agent(s) you would dispatch and in what order
2. What task description you would give each agent
3. Whether any verification step is needed before presenting results to the user
